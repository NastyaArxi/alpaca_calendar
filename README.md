## 🍺 Der Goldene Krug — лендинг пивного бара

**Посмотреть сайт:** https://nastyaarxi.github.io/alpaca_calendar/der-goldene-krug/

Одностраничный сайт баварской пивной: тёмный «подвальный» зал, золото пива и пены, готический шрифт в заголовках. Чистые HTML, CSS и JavaScript — без фреймворков и сборки.

### Что есть на странице

- **Заставка** — кружка наполняется пивом, потом появляется «Prost!».
- **Первый экран** — фото зала с параллаксом и световым пятном за курсором, всплывающие пузырьки, вращающийся значок «Ein Prosit».
- **Бегущие строки** с сортами пива.
- **Цифры** — счётчики, которые досчитывают при появлении на экране.
- **Reinheitsgebot** — рассказ о Законе о чистоте пива и четырёх ингредиентах.
- **«Как рождается кружка»** — секция, привязанная к прокрутке: шаги варки сменяются, а большая кружка наполняется по мере скролла.
- **Полка сортов** — шесть карточек едут горизонтально при вертикальной прокрутке.
- **Меню** с вкладками «Пиво» и «Кухня» (переключаются и стрелками на клавиатуре).
- **Вечера недели** — карточки переворачиваются при наведении или нажатии.
- **Бронирование стола** — форма с проверкой полей и экраном подтверждения.

### Технически

- Адаптивная вёрстка от 360 px до широких экранов.
- Анимации прокрутки работают во всех современных браузерах: JS считает прогресс секции, а CSS-анимации «перематываются» под него.
- Учтены `prefers-reduced-motion` (анимации отключаются, секции становятся статичными), видимый фокус клавиатуры, ARIA-роли у вкладок и формы.
- Шрифты: Playfair Display, Oswald, Manrope, UnifrakturMaguntia (Google Fonts).

### Запустить локально

Откройте `der-goldene-krug/index.html` в браузере или поднимите любой статический сервер:

```bash
python3 -m http.server 8000
```

и перейдите на http://localhost:8000/der-goldene-krug/

### Публикация

Сайт публикуется на GitHub Pages workflow-ом [`.github/workflows/pages.yml`](.github/workflows/pages.yml) при каждом пуше в `main`. Если Pages ещё не включены: **Settings → Pages → Source: GitHub Actions**.
