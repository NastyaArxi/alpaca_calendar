# Гномы Деда Мороза

HTML5-головоломка для Яндекс Игр в жанре Pixel Flow. Отряды гномов бегут по дорожке вокруг пиксельной картинки и уносят крайние блоки своего цвета. Отряд, который не потратил все блоки за круг, садится на скамейку. Если скамейка заполнена, уровень проигран.

- `engine.js` — логика игры и генератор уровней (без DOM)
- `pictures.js` — картинки уровней
- `platform.js` — SDK Яндекс Игр (реклама, сохранения); вне Яндекса игра работает автономно
- `game.js`, `index.html`, `style.css` — интерфейс

Запуск локально: `python3 -m http.server` в этой папке.
Проверка уровней (каждый проходится ботом): `node tests/engine.test.js`.
Архив для площадки: `./build.sh` → `dist/gnomes.zip`.
