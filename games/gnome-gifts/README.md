# Гномы и подарки

HTML5-головоломка для ВКонтакте и Яндекс Игр в жанре «Переноски муравьями» / Pixel Flow, оформленная по макету дизайнера.
На поле — пиксельная игрушка. Нажимаешь на цветную плитку в очереди — она встаёт в ячейку, и гномы Деда Мороза выбегают из неё,
берут блоки своего цвета с края игрушки и несут в мешок. Если всем плиткам в ячейках нечего брать — проигрыш.

- 48 уровней = 48 игрушек из макета, 4 главы: Лёгкие (5 ячеек, 3 колонки, плитка до 40), Средние (до 48),
  Сложные (4 колонки, до 56), Мастер (4 ячейки, до 64). Звёзды: 3 — без помощи, 2 — с «+1 ячейкой», 1 — после продолжения за рекламу.
- Экраны по макету: старт, карта уровней, уровень, победа, «Гномам нечего брать».

Файлы:
- `toys.js` — игрушки (сжатая запись пикселей из макета), палитра из 19 цветов, правила глав
- `engine.js` — доступность блоков, генерация уровней по правилам главы, проверка решаемости (без DOM)
- `platform.js` — ВКонтакте (VK Bridge) и Яндекс Игры: реклама, сохранения
- `game.js`, `index.html`, `style.css` — экраны, гномы, музыка
- `fonts/`, `fonts.css` — Montserrat (SIL OFL 1.1, `fonts/OFL.txt`)

Проверка: `node tests/engine.test.js`. Архивы: `./build.sh` → `dist/gnome-gifts-vk.zip` и `dist/gnome-gifts-yandex.zip`.
