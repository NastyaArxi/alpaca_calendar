# Пиксельная Ёлка

HTML5-головоломка для Яндекс Игр: нажимаешь на верхние блоки колонок, три одного цвета на полке закрашивают часть новогодней пиксельной картинки. Полка заполнилась — проигрыш.

- `pictures.js` — картинки уровней (добавить уровень = дописать картинку)
- `levelgen.js` — генератор уровней, решаемых по построению
- `platform.js` — SDK Яндекс Игр (реклама, сохранения); вне Яндекса игра работает автономно
- `game.js`, `index.html`, `style.css` — сама игра

Запуск локально: `python3 -m http.server` в этой папке, открыть http://localhost:8000.
Проверка уровней: `node tests/levelgen.test.js`.
Архив для загрузки на площадку: `./build.sh` → `dist/pixel-elka.zip`.
