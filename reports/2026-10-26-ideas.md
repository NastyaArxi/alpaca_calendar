### Идея 1: Пиксельная Ёлка (рабочее название)

| Поле | Содержание |
|---|---|
| **Core loop** | Тапаешь по колбе с цветными «пикселями» → они улетают на свободную полку по цвету → полный набор одного цвета закрашивает часть картинки → собрать картинку целиком. Проигрыш: полки забиты, ходов нет |
| **Why now** | Food Hunt: Pixel Puzzle — №1 в трендах (Global Games Forum, сентябрь 2026). У Pixel Flow, по одной оценке, $94 млн IAP (nextbiggames, 2026; не проверено) |
| **Lifecycle stage** | Растущая. Окно 3–6 месяцев (оценка) |
| **Twist** | Картинки — русский Новый год: ёлка, оливье, мандарины, Дед Мороз, салют над панельками. В 3-секундном ролике картинка «проявляется» пиксель за пикселем |
| **Keep vs change** | Оставить: сортировку по цветам и проявление картинки. Изменить: тему, мягкую рекламу (главная жалоба в топ-головоломках — агрессивная реклама) и коллекцию открыток |
| **Automation lever** | Любой PNG 16×16–32×32 → палитра → уровень. Солвер проверяет решаемость, сложность = число цветов × размер полки. Картинки можно сгенерировать или нарисовать в пиксельном редакторе |
| **Social hook** | Таймлапс «пустой холст → новогодняя картинка» за 5 секунд. Собранную открытку можно скачать и отправить |
| **Monetization** | Rewarded: +1 полка, отмена хода, «перемешать», продолжить после проигрыша. Межстраничная — между уровнями начиная с ~5-го. IAP (позже): «без рекламы», наборы открыток |
| **MVP scope** | 1 экран, 1 механика, 30–50 уровней, прогресс в облаке Яндекса, SDK Яндекс Игр, русский и английский. Около 2 недель, веб |
| **Not in MVP** | Мета-город, ежедневные задания, лидерборды, магазин скинов |
| **Kill switch** | D1 < 25% → стоп; 25–35% → итерация; ≥ 35% → масштаб (gamegrowthadvisor, 2026, казуальная головоломка, вторичный). Средняя сессия < 4 мин → упростить начало (оценка). Нужно ~900 игроков для чтения D1 |
| **Risks** | 1) Модерация Яндекса затянется → отправить до ~10 ноября. 2) После 8 января тема устаревает → движок принимает любые картинки, весной выходит обычная версия с едой и животными |
| **Scores** | 4 · 5 · 4 · 4 · 4 · 5 · 5 = **31/35** |

### Идея 2: Снегоуборщик

| Поле | Содержание |
|---|---|
| **Core loop** | Ведёшь пальцем снегоуборщик по двору → снег «срезается» с приятным звуком → получаешь монеты → улучшаешь ширину ковша и скорость → следующий двор. Проигрыша нет (idle), есть таймер на звёзды |
| **Why now** | Bulldozer Master: Crush & Mine — №2 в трендах (Global Games Forum, сен 2026), №10 по росту загрузок (Sensor Tower, сен 2026) |
| **Lifecycle stage** | Зарождающаяся → растущая |
| **Twist** | Российская зима: панельки, «жигули» под сугробом, дворник с лопатой. Под снегом спрятаны находки (мандарин, потерянная варежка) |
| **Keep vs change** | Оставить: «сатисфай»-срезание и петлю прокачки. Изменить: сеттинг, 2D вид сверху вместо 3D |
| **Automation lever** | Дворы генерируются процедурно: маска снега + препятствия + находки. Баланс прокачки — формулой |
| **Social hook** | Ролики «до/после» двора и вирусный звук хруста снега |
| **Monetization** | Rewarded: ×2 монеты, турбо-ковш на 30 секунд, автоуборщик. Межстраничная — между дворами |
| **MVP scope** | 2D canvas, 1 машина, 3 улучшения, 10 дворов. 2–3 недели |
| **Not in MVP** | Несколько машин, 3D, сюжет |
| **Kill switch** | D1 < 25% → стоп (тот же источник). Для idle важнее D7 и длина сессии, бенчмарк не найден (не проверено) |
| **Risks** | 1) «Сатисфай» в 2D может выглядеть хуже, чем в 3D → прототип эффекта за 2 дня, потом решение. 2) Прокачка требует баланса → таблица формул и автотест баланса |
| **Scores** | 3 · 4 · 5 · 4 · 4 · 4 · 4 = **28/35** |

### Идея 3: Мандаринодоку (самый маленький вариант)

| Поле | Содержание |
|---|---|
| **Core loop** | Ставишь новогодние символы в сетку 4×4 / 6×6 так, чтобы они не повторялись в строке, столбце и блоке → решённая сетка открывает часть адвент-календаря |
| **Why now** | Meowdoku: +7 позиций, 8-е место по загрузкам мира, 11,5 млн установок (AppMagic через Gamedev Reports, сен 2026) |
| **Lifecycle stage** | Растущая |
| **Twist** | Адвент-календарь: 1 новый пазл в день до 31 декабря. Символы вместо цифр, понятно детям и взрослым |
| **Keep vs change** | Оставить: правила судоку и уютную тему. Изменить: символы, ежедневный ритуал |
| **Automation lever** | Генератор судоку и солвер с проверкой единственности решения — стандартные алгоритмы, бесконечно уровней |
| **Social hook** | Карточка результата «День 12 ✅ за 1:43» (как в Wordle) |
| **Monetization** | Rewarded: подсказка, проверка ошибок. Межстраничная — после пазла |
| **MVP scope** | 1 экран, генератор, 3 размера сетки. ~1 неделя |
| **Not in MVP** | Рейтинги, режимы на время |
| **Kill switch** | D1 < 25% → стоп (тот же источник) |
| **Risks** | 1) Слабая виральность → ставка на ежедневную карточку. 2) Много судоку в каталогах → тема и адвент-календарь |
| **Scores** | 5 · 5 · 2 · 3 · 3 · 4 · 5 = **27/35** |

## Рекомендация
**Начать с идеи 1, «Пиксельная Ёлка».** У неё лучший балл, механика растёт прямо сейчас, а уровни можно делать автоматически из картинок. После праздников тот же движок продолжает жить с другими картинками. Её можно успеть за 2 недели и отправить на модерацию до ~10 ноября.
Идея 3 подходит как «быстрый второй релиз» в декабре, если ёлка пройдёт модерацию рано.
